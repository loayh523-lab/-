# ميثاق المؤمن

تطبيق إسلامي شيعي باللغة العربية، يُبنى على مراحل مع مراجعة الكود والاختبارات قبل اعتماد كل مرحلة.

## خطة العمل
1. تصميم الواجهة والتنقل.
2. القرآن الكريم.
3. الأدعية والزيارات مع مراجعة النصوص ومصادرها.
4. التسبيح والتقويم ومواقيت الصلاة.
5. الاختبارات وبناء نسخة Android.

> لا تُعد الميزات الوهمية ميزات مكتملة؛ ستُضاف الوظائف الفعلية بعد تجهيز مصادرها والتحقق منها.
